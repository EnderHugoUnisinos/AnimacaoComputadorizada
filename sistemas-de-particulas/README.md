# Exploração de Sistemas de Partículas

---

## Descrição do Projeto

> Este jogo foi desenvolvido como parte da disciplina *Animação Computadorizada* com o objetivo de explorar a implementação de sistemas de partículas.

---

## Estrutura do Projeto


| Arquivo               | Descrição                                                                     |
|-----------------------|-------------------------------------------------------------------------------|
| `ParticleManager.cs`  | Gerencia o comportamento de GPUParticles3D para obter diferentes resultados.  |

---
## Informações Técnicas

- **Engine:** Godot 4.7 Mono  
- **Linguagem:** C#  
- **Dependências:** .NET  
- **Plataforma-alvo:** Desktop (Windows/Linux)

---

## Checklist de Requisitos

- [x]   Definir os atributos das partículas que você desejar, com no mínimo 3 variações nesses atributos (como cor e formas diferentes) ao longo do tempo
- [x]   Definir no mínimo 3 formas de nascimento diferentes (emissores diferentes)
- [x]   Definir no mínimo 5 comportamentos diferentes para a evolução das partículas
- [x]   Definir pelo menos 2 critérios de morte para que as partículas desapareçam da tela depois de um tempo
