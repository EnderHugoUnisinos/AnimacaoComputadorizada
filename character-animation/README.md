# Pipeline de Geração de Personagem Animado por Esqueleto

---

## Descrição do Projeto

> Este jogo foi desenvolvido como parte da disciplina *Animação Computadorizada* com o objetivo de explorar criação de personagens, animações e as transições entre elas.

---

## Estrutura do Projeto


| Arquivo               	 | Descrição                           |
|--------------------------------|-------------------------------------|
| `animationcontroller.gdscript` | Controla as transições da blendtree.|

---
## Informações Técnicas

- **Engine:** Godot 4.7 Mono
- **Linguagem:** GDScript
- **Dependências:** .NET 
- **Plataforma-alvo:** Desktop (Windows/Linux)

---

## Checklist de Requisitos

- [x]   Um personagem animado com pelo menos 3 animações diferentes, implementado em
um motor de jogo.
- [x]   Transições suaves entre as animações, utilizando técnicas como blend trees ou
animation masks.
