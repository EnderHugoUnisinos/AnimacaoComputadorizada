# Geração de Animações Utilizando o Espectro Sonoro
---

## Descrição do Projeto

> Este jogo foi desenvolvido como parte da disciplina *Animação Computadorizada* com o objetivo de explorar a Geração de Animações Utilizando o Espectro Sonoro.

---

## Estrutura do Projeto


| Arquivo                   | Descrição                                                                  |
|---------------------------|----------------------------------------------------------------------------|
| `MainScript.gd`  	        | Logica geral do programa, utiliza as frequencias para interagir com a cena.|
| `AudioReactive.gd`  	    | Captura e armazena as frequencias de magnitude do audio.                   |
| `RainImpactDetector.gd`  	| Cosmetico, cria decals no na superficie agindo como respingos da chuva.    |
| `RainSplash.gd`  	        | Reduz a opacidade do respingo e o deleta em um timer.                      |

---
## Informações Técnicas

- **Engine:** Godot 4.7 Mono  
- **Linguagem:** GDScript  
- **Dependências:** .NET  
- **Plataforma-alvo:** Desktop (Windows/Linux)
